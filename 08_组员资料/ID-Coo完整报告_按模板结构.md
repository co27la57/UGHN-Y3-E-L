## 1. 确定EID的限制条件及与LIS相关的法规

### 1.1 背景与政策时间表

牛只身份识别是奶牛场开展个体管理、生产记录和疾病追溯的基础。本项目面向英格兰北部的荷斯坦—弗里斯兰牛，设计可在既有处理设施上实施的逐头身份核验与异常分流装置。

Defra于2026年7月23日更新的牲畜信息转型计划指出，英格兰新牛只追溯服务计划于2027年交付，并预计在2027年对新生犊牛引入低频电子身份识别。现有CTS在服务推广至所有养牛者前继续运行。因此，本报告采用更新后的官方时间表，修正任务书中较早的2026年推广表述。[1] 相关制度改革应结合政府咨询响应及后续正式实施通知理解。[2]

电子耳标有助于减少人工抄录错误，但可能丢失、电子失效或因姿态和读区条件而漏读。Roberts等对美国四处牧场共4,316头肉牛开展研究，其中五年随访牧场的累计丢失或读取失败比例达到19.8%。该数值属于特定肉牛研究中的多年累计结果，不能作为英格兰奶牛场的年度故障率。[6]

### 1.2 主要限制及设计影响

| 限制条件 | 对ID-Coo的影响 |
| --- | --- |
| 新生牛只电子识别政策采用低频技术 | 第一版采用兼容动物低频电子耳标的设备，不以UHF为默认方案 |
| 过渡期存在电子耳标与传统耳标牛 | 保留人工核验；不能把传统耳标牛全部认定为耳标损坏 |
| 官方身份编号不能由设备自行推测或生成 | 无有效读数时只建立事件编号，正式身份字段为空 |
| RFID读取受头位、金属及电气干扰影响 | 现场验证读区、天线位置和邻牛串读，机械隔离不等于射频隔离 |
| 内部通行不等于法定场所间转移 | 内部分流记录不自动上报为牛只转移 |
| 新服务具体接入条件尚需确认 | 第一版提供数据导出，正式直连在规范与授权明确后实施 |
| 动物健康与追溯政策具有地区差异 | 初期按英格兰设计，跨地区推广时重新核对制度与接口 |

官方过渡安排允许继续通过电子读取、护照条码或目视读取耳标报告信息，不要求立即为全部现有牛群重新安装电子耳标。[1] 读卡器和耳标兼容性应参考ISO 11784／11785及ICAR资料；兼容这些标准不等于取得英格兰官方耳标使用资格。[10]

### 1.3 耳标更换与记录责任

现行官方指导要求，发现官方耳标丢失或损坏后，在28天内订购并安装替换耳标；缺少规定耳标的牛在补装前不得移出所在场所。[3] 系统应建立复核任务和期限记录，但身份确认与耳标更换责任仍由农场承担。

牛只移入或移出场所后，应按现行要求更新场所登记册，并在规定期限内报告。指导中分别列出36小时的场所记录要求及3天的转移报告要求。[4], [5] 系统界面须区分本地保存、待申报和申报成功，不能把保存数据当作履行法定报告义务。

## 2. 农场环境中错误识别奶牛的后果

| 因果链 | 对农场的后果 | 本方案应采取的措施 |
| --- | --- | --- |
| 治疗记录绑定错误牛只 → 处理和休药期信息错配 | 可能对错误对象操作，或影响治疗乳汁管理 | 未核实身份不更新正式个体记录 |
| 产奶、繁殖及历史记录错配 → 个体表现判断失真 | 影响配种、饲养或淘汰安排 | 保留身份可信状态和修改历史 |
| 分流使用邻牛编号 → 目标牛未被留住 | 增加再次寻找和赶牛劳动 | 将读数、当前事件及实际出口关联 |
| 官方编号错误 → 场所或转移记录矛盾 | 影响追溯和后续核查 | 法定业务信息须经审核 |
| 反复重新分隔牛只 → 人牛接触次数增加 | 增加人员暴露和牛只应激 | 在围栏外控制，提供安全接管 |

身份识别不仅服务于LIS记录，也支撑牛奶收购方关注的乳汁管理与质量控制。AHDB要求高风险牛明确标识，并确保接受抗生素治疗的牛所产牛奶不进入奶罐。[7] 身份错配可能削弱这些措施，但ID-Coo不检测药物残留，也不能替代挤奶端乳汁分离。

官方追溯制度强调准确记录，以支持持续追踪和疾病防控。[4] HSE也强调适用的牛只处理设施、人员培训及安全操作。[8] 因此，本方案将身份可信度、实际出口和可安全接管同时纳入设计，而不只追求读取次数。

## 3. 构思方案与价值主张画布

### 3.1 方案概述

ID-Coo采用“单头缓冲段—末端检测段—双出口分流区”的布局。机械分隔建立独立检测对象，低频RFID读取电子耳标，空气耦合超声测距辅助监测占位和通行过程。身份读取有效的牛返回正常通道；有限重读后仍无法确认身份的牛，在支路可用时进入待复核围栏。

每次通行建立独立事件，把读取结果、门位和实际去向联系起来，由人工复核完成身份恢复。“正常”仅表示本轮电子核验通过；“需要复核”不表示牛患病。

第一版由人员在围栏外确认单头进牛，自动执行后续读取与条件分流。全自动进牛仅在安全分隔得到验证后实施。

### 3.2 价值主张画布

**目标客户：**英格兰北部具有既有处理通道、电子耳标条件和较高核验负担的奶牛场。为第一版验证，优先筛选约100—250头成年奶牛的农场；该范围是产品筛选条件，不是当地规模分布的统计结论。

| 画布维度 | 具体内容 |
| --- | --- |
| 客户任务 | 确认当前牛只身份；找出需要核验耳标的牛；完成准确个体记录；保持通行顺畅；安全处理牛只；控制投入 |
| 客户痛点 | 漏读、串读和人工抄录错误；异常牛难以再次寻找；处理记录分散；紧跟、停步和倒退；改造费用及维护不确定 |
| 客户收益 | 身份可靠对应；异常牛留在可管理区域；完整核验记录；可在围栏外操作；投入和经济收益可核对 |
| 产品与服务 | 缓冲与检测结构、RFID、超声占位监测、条件分流、事件记录及复核界面；勘察、安装、培训和维护 |
| 痛点缓解方式 | 机械分隔减少共同进入读区；事件编号阻止延迟结果误用；有限重读避免无限等待；围栏减少再次寻找；故障与身份异常分别处理 |
| 收益创造方式 | 展示已核验、待复核和已处理状态；记录计划与实际出口；利用既有设施逐步改造；通过现场测量证明净劳动收益 |

### 3.3 客户与价值主张的匹配

购买决策者主要是农场主或经营负责人，日常使用者为牛群管理员及工作人员。兽医、安装商和农场软件供应商可参与评估。

以上需求源于任务分析及案头资料，尚未完成正式客户访谈。试点应记录异常频率、再次寻找时间、现有通行速度和愿付价格，验证客户是否愿为该流程付费。系统不承诺未经证实的产奶量提升。

## 4. 确定所属竞争类别及差异化因素

ID-Coo属于牛只身份核验与分流管理设备。比较对象为人工核验、手持RFID、固定式RFID、机械分流设施及集成牛群管理系统。

| 比较对象 | 共性点 | 拟形成的差异点 | 本方案的不足 |
| --- | --- | --- | --- |
| 人工目视与手动分流 | 身份确认与异常处理 | 自动记录事件并执行条件分流 | 仍需人工身份恢复和外观检查 |
| 手持RFID读取 | 获取电子耳标编号 | 固定读区与分流联动，减少寻找 | 投入更高，需要固定场地 |
| 固定RFID读取 | 自动获取编号 | 以单头事件管理读数并确认去向 | 逐头隔离可能限制速度 |
| Arrowquip机械设施 | 通道及出口选择 | 增加读取、联锁和异常记录 | 自动化改造尚需验证 |
| DeLaval分流设备 | 自动选择牛只去向 | 聚焦身份读取异常的复核流程 | 缺少成熟服务和系统基础 |
| GEA DairyNet分流模块 | 分流规则与个体记录关联 | 计划独立部署并导出数据 | 接口和整合尚未验证 |

Arrowquip提供可调通道及侧向分流结构，但其组件存在不等于本方案已实现安全自动进牛。[13], [14] DeLaval已有与牛群管理系统配合的分流设备，GEA也提供规则、区域和日志管理。[17], [18] 因此，自动分流本身不是独有创新。

本产品必须保持可靠读取、安全通行、可维护结构和服务能力等共性。拟议差异化在于不把读取异常直接认定为耳标损坏，不必先获得正式编号即可安全保留当前对象，并记录人工复核结果。这些是定位与设计主张，尚不能写成已实测优于竞争产品的结论。

## 5. 进一步开展竞争分析

### 5.1 波特五力分析

**现有竞争者：竞争较强。**成熟厂商已有自动分流与牛群管理系统。ID-Coo应聚焦独立身份核验及异常处置，避免第一阶段全面替代挤奶管理系统。[17], [18]

**潜在进入者：威胁中等。**RFID、门驱动和工业控制组件可获得，但现场可靠性、安全验证与售后服务构成门槛。项目需要积累验证数据和可重复安装流程。

**替代方案：威胁较高。**人工目视、手持读取及既有分流设备能够满足部分需求。异常少、人工负担低的农场可能不值得购买完整系统。

**买方：议价能力较高。**农场主可以延迟投资，也会要求证明回收期。销售前应测量实际劳动负担，而不是仅展示功能。

**供应商：议价能力中等。**钢结构和部分控制元件有替代来源，但读卡器、天线和安全部件须满足兼容及验证要求，不能为降价随意替换。

五力分析要求产品用途明确、改造范围受控、收益可核查，并具备供应备选和本地维护能力。

### 5.2 SWOT分析

| 类型 | 主要内容 | 应对措施 |

| 机会 | 电子身份和追溯转型；既有农场设施改造 | 面向准备转型且具有实际核验负担的客户 |
| 威胁 | 成熟设备竞争；成本超预算；占位误判或串读 | 把现场勘察和验证作为销售前置条件 |

### 5.4 客户期望属性与差异化结论

## 6. 产品与服务及竞争分析：独特卖点

**ID-Coo通过逐头核验、异常牛安全分流和完整事件记录，帮助具有既有处理通道的奶牛场减少身份错配及人工再次寻找牛只的负担。**

| 收入来源 | 设备及安装收入、年度服务、经确认的软件适配服务 |
| 关键资源 | 机械及控制设计、验证数据、供应商、安装与维护能力 |
| 关键活动 | 现场适配、集成、安全验证、调试、培训和异常支持 |
| 关键合作伙伴 | 通道制造商、RFID及控制部件供应商、安装商、试点农场 |
| 成本结构 | 部件、安装、验证、研发、维护、保险、销售和管理 |

表中合作伙伴是拟议角色，不表示已经建立商业合作。

规划采用一次性安装收费及年度服务收费。年度服务覆盖约定检查、支持及更新；重大碰撞、土建和范围外维修另行报价。停止续订后，本地基本核验、分流和记录功能仍应可运行。

市场进入先通过少量试点测量读取、排队和净劳动时间，再由区域安装商复制验证后的布局。营销材料应明确适用条件、人工职责、已验证性能、全部费用和不适合安装的情况。

## 8. 批判性分析

### 8.1 市场规模与口径

AHDB在2026年4月调查估计，大不列颠约有6,850家奶业生产者。该数值不是英格兰北部客户数量，也不包含北爱尔兰。[19] Defra的2025年英国牲畜统计列出约184.9万头奶牛，属于牛群规模，同样不能作为设备客户户数。[20]

Defra的2024年区域数据列出西北部奶牛群约27.1万头、约克郡与亨伯约7.5万头、东北部约1.3万头，合计约35.9万头。[21]

缺少逐户客户清单时，使用区域农业面积A、平均农场面积Ā及奶业农场比例d作粗略推算：

```text
区域奶业农场数量 N ≈ (A / Ā) × d
```

| 区域 | 农业面积／公顷 | 平均农场面积／公顷 | 奶业农场比例 | 推算数量 |
| --- | ---: | ---: | ---: | ---: |
| 西北部 | 893,000 | 72 | 10% | 约1,240家 |
| 约克郡与亨伯 | 1,086,000 | 91 | 3.4% | 约406家 |
| 东北部 | 581,000 | 138 | 1.5% | 约63家 |
| 合计 | — | — | — | 约1,700家 |

基础数据来自Defra。[21] 由于原始数据四舍五入，且奶业农场分类与牛奶生产者登记口径不同，约1,700家是本报告推算，不是官方发布的精确客户数量。

### 8.2 可服务比例与销售目标

筛选通道空间、电子耳标覆盖、劳动负担、围栏能力、现金流及既有系统后，规划假设40%的潜在农场适用：

```text
SAM = 1,700 × 40% = 680家
```

40%尚未获得客户调查支持。若三年累计安装50套，则占区域潜在市场约2.9%，占假设可服务市场约7.4%。第一年10套、第二年15套、第三年25套仅为销售目标，须由验证、安装能力和实际订单支持。

### 8.3 客户与产品匹配及必要调整

产品适合异常核验具有实际劳动成本、且能利用既有设施的客户。小牛群、极低异常率、缺少围栏或已有成熟系统的农场，不应默认纳入目标客户。

逐头隔离可能成为通行瓶颈。验证前不直接串联到全部牛必须经过的高峰挤奶出口，应先在既有处理通道或有旁路的核验区域试点。若新增赶牛、等待及维护抵消了节省，应调整流程或不安装。

### 8.4 整体判断

方案的价值是明确当前通行对象、身份可信状态、实际出口和复核结果。概念合理性不能替代现场证据。商业实施取决于安全分隔、RFID归属、出口一致性及净收益四项验证。建议先采用人工确认单头进牛，再根据验证结果决定是否推进全自动化和扩大销售。

## 10. 提供解决方案的技术描述

本节面向直属主管说明结构、传感器、数据汇聚、控制、软件、接口和定价。第一版是人工确认单头进牛、自动读取与条件分流的系统，尚未完成样机验证。

### 10.1 物理布局

```text
牛群等待区
    │
入口分隔门 G0
    │
单头缓冲段 A
    │
检测段后门 G1
    │
末端检测段 B
    │
检测段前门 G2
    │
分流区及分流门 D
    ├── 正常返回通道
    │
    └── 异常支路 → 围栏入口门 H → 待复核围栏
                                      │
                                独立人工处理出口
```

**图1：通道及分流功能布局。**图示不表达施工比例、门转轴或运动范围。正常与异常牛均向前离开B段，D只形成导向边界，不推动或挤压牛身。

一个缓冲段和一个检测段先验证核心流程。增加前方通道提高等待容量，但不必然提高末端速度，还增加门和故障点。

### 10.2 机械结构及尺寸

通道净宽可调，段长按目标牛群体型、停步姿态和门运动空间确定。固定长度不能独立保证每段一头牛。

Arrowquip通道宽度调节约526—800毫米，提供8英尺及10英尺模块；英国产品展示30°侧向分流。[13], [14] 参数仅作参考，不能直接作为施工尺寸，模块长度也不能等同于单牛容纳长度。

结构设计覆盖防滑排水、无尖锐突出物、门轨与铰链防护、头颈与腿部间隙、连续出口边界和围栏外操作位置。设计不默认需要夹持或固定牛头。官方福利指导要求保持通道和地面良好，减少打滑、突出物及强迫赶牛。[9]

### 10.3 技术分工与能力边界

| 子系统 | 功能 | 能力边界 |
| --- | --- | --- |
| 机械分隔 | 建立独立空间并阻断跟入 | 不证明射频读区没有邻牛 |
| 超声测距 | 监测占位和进入、离开过程 | 不识别身份，不独立证明牛只数量 |
| RFID | 读取电子编号 | 不证明外观完好，不直接判定无读数原因 |
| 门控与分流 | 执行确认后的通行及出口选择 | 不进行疾病诊断或正式身份认定 |
| 人工复核 | 检查标识、核对记录、处理耳标 | 无可靠证据时不按牛群排列猜测身份 |

外壳损坏但芯片可读，或缺失非电子耳标，本组合可能无法自动发现。覆盖全部外观损坏需要人工目检或另行验证的检查功能。两侧官方标识均不足以确认身份时，应按官方程序核查，不能创建替代正式编号。[3]

### 10.4 超声布置及判定

| 测点 | 建议位置 | 用途 |
| --- | --- | --- |
| U-A | A段 | 辅助判断空段及占用 |
| U-IN | G1附近 | 进入及疑似后牛探入监测 |
| U-B1 | B段后部 | 进入及后部占位变化 |
| U-B2 | B段前部 | 是否进入预定读区的辅助判断 |
| U-N | 正常出口 | 通过及清空监测 |
| U-Q | 异常支路／围栏入口 | 异常路径通过监测 |

上述六个功能测点是规划配置，不表示单个测点可覆盖全部门口。分流区或入口覆盖不足时必须增设监测，不能因预算留下盲区。

超声距离关系为：

```text
d = c × Δt / 2
```

d为距离，c为声速，Δt为发射至回波接收时间。空段时采集背景，运行输出为空、占用或不确定。无回波、过期、超量程和设备异常均归为不确定；单一回波峰不等于一头牛。

超声存在盲区，回波受目标形状、温度、气流及声源影响，牛体不是理想平面反射目标。[15] 多测点评估厂家支持的错时发射，以减少串扰，并核查轮询延迟。[16]

### 10.5 RFID模块

评估兼容动物低频电子耳标、支持HDX与FDX-B的工业读卡器及配套天线。系统只自动读取已佩戴的低频电子耳标；未佩戴此类耳标的牛须人工核对身份或采用替代流程，未读到编号本身不证明耳标损坏。Tru-Test XRP2可作功能参考，最终型号须现场选型。[11]

天线设在B段头耳通过区域外侧，避免直接撞击。测试左右耳、头位变化、A段及围栏邻牛、钢结构、门位变化和电气干扰。厂家指南要求读区只容纳一个动物，并指出金属和电气设备影响。[12]

同一编号在本轮去重。读数重复多不证明其属于当前牛；一个编号也不证明只有一头牛。设备诊断正常不保证每次读取成功。

### 10.6 控制系统、电气与功能框图

```text
超声状态、RFID读数、门位反馈 → PLC（通行状态机与事件判定）
PLC → 门驱动：开／关／停动作请求
急停、受阻、防护状态 → 安全相关控制 → 门驱动：独立停止／禁止
PLC → 本地事件日志与农场主界面 → 农场软件：第一版可审计导出
```

**图 2 — 功能控制、安全与数据接口。**PLC 向门驱动发出动作请求；安全相关控制通过独立路径停止或禁止驱动，具体保护功能由现场风险评估确定。数据接口不能绕过该路径。

概念电气结构为场所供电经隔离、保护及配电进入驱动回路和控制电源；传感器与门位反馈接入 PLC，急停和保护装置接入独立于普通数据路径的安全相关控制。具体电压、驱动功率、线缆保护及接地方案须按所选设备和现场设计，不能以本框图代替施工电路图。

安全相关控制按现场风险评估确定保护功能及所需性能，采用机械功能安全的通用设计方法；本章不声称达到某一性能等级。

| 接口 | 信号或数据 |
| --- | --- |
| 超声传感器 → PLC | 距离、占位状态、更新时间及诊断 |
| RFID 读卡器 → PLC | 耳标编号、接收时间及设备状态 |
| 门位反馈 → PLC | 开位、关位和故障状态；设有门锁时报告锁定状态 |
| 安全装置 → 安全相关控制 | 由风险评估确定的急停、防护和其他保护输入 |
| PLC → 门驱动 | 开、关或停止动作请求 |
| 安全相关控制 → 门驱动 | 独立停止或禁止驱动 |
| PLC ↔ 本地事件日志与农场主界面 | 事件及设备状态；授权人工操作作为过程请求返回 PLC |
| 本地事件日志与界面 → 农场软件 | 第一版可审计导出 |

### 10.7 单头进牛与联锁

首次安全分隔是未验证的关键环节。第一版由人员在围栏外操作并确认A段只有一头牛；G0关闭、门口无身体占用后才转移。超声不能代替该确认。取消人工确认前须完成自动分隔、防夹和异常验证，经济测算须计入人员时间。

主要过程联锁（不能替代安全相关控制）：

1. G0与G1不同时开放，G1与G2不同时开放。
2. B段及分流区清空、G2关闭、A段单头状态确认后才打开G1。
3. 牛完整进入B段且关门区域安全后关闭G1。
4. G1、G2均确认关闭、牛在读区且无疑似跟入时才开始有效扫描。
5. D未到位不能开G2；放行时G1保持关闭。
6. 牛占用D运动范围时不能切换出口。
7. 不以固定时间推定牛已离开，不把未知路径视为畅通。

### 10.8 状态机与判定算法

| 状态 | 动作 | 下一状态条件 |
| --- | --- | --- |
| S0自检 | 检查设备、保护与门位 | 符合启动条件 |
| S1建立单头缓冲 | 人工确认A段独立对象 | G0关闭且分隔有效 |
| S2进入B段 | G2关闭，打开G1 | 完整进入、关门区域安全 |
| S3隔离扫描 | 关闭G1，建立扫描窗口 | G1、G2均关闭 |
| S4判定 | 去重、核对归属、有限重读 | 有效身份或复核结果 |
| S5设出口 | 检查路径并设置D | 目标可用、D到位 |
| S6放行 | 开G2，保持G1关闭 | 当前牛离开 |
| S7复位 | 核对实际出口并安全关门 | B及分流区清空 |
| SF暂停 | 停止接牛并提示处理 | 故障排除，人工确认恢复 |

本方案使用规则状态机，不要求机器学习。每次进牛建立独立事件；扫描窗口、重试次数和稳定判定阈值通过试验设定。不同事件的结果不能混用：窗口外或已结束事件的延迟结果保留在日志中，不作用于下一头牛。

### 10.9 分流决策与异常处理

| 情况 | 处理 |
| --- | --- |
| 有效单头通行且获得可归属当前牛的有效编号 | 正常出口 |
| 有牛，有限重读仍无编号，设备未发现故障 | 支路可用时送待复核围栏，原因记为未读到 |
| 多个编号或归属不清 | 保持B段，有限重读；仍不确定则复核 |
| 疑似多牛、占位不确定或门口占用 | 暂停，重新分隔或人工接管 |
| RFID离线、超声失效、门位异常 | 设备故障暂停 |
| 支路堵塞或围栏满员 | 停止接牛，处理路径 |

未知身份时仍由当前事件管理B段对象，但机械状态未知时不能继续自动分流。连续无读数触发设备检查，避免整批牛被错误分流。扫描超时只触发复核或暂停，不绕过安全条件。

### 10.10 防夹、失电及人工接管

普通超声不作为唯一防夹保障。门运动风险由经验证的覆盖检测、受阻保护、机械防护和安全控制共同处理。急停或失电停止危险运动，按具体机构保持可控状态；不规定全部门立即关或开。

控制记录设备可用短时后备电源保存状态和提示，不假设其驱动所有门。人员须可从设备外解除驱动并按验证程序释放牛只。复电后检查实际门位和占位，不自动接续未完成的危险动作。使用和维护遵循适用设施、培训与检查原则。[8]

### 10.11 待复核围栏

围栏设独立入口、防返回和人工处理出口，不赋予疾病隔离功能。H仅在牛完整通过且门口清空后关闭。工作人员在围栏外操作，满员时暂停上游。

容量规划关系为：

```text
C ≥ λq × th + Cm
```

λq为异常进入速率，th为处理间隔，Cm为容量余量。平均负荷公式不保证连续异常时容量足够，仍须满员监测。预算情景暂利用约6头容量的既有待处理围栏；实际容量、饮水及停留管理由现场确认。

### 10.12 数据汇聚、软件与农场主界面

每个事件记录事件号、开始与结束、扫描与放行时间、占位和门位摘要、原始及去重读数、设备诊断、判定原因、计划与实际出口、人工处理人员及修改历史。

事件号与官方身份分开，未读到时身份为空。人工核实后建立关联，保留原异常及更改记录。可视标识不足时继续官方核查，不按顺序猜测。[3]

界面区分电子核验通过、身份待复核、设备或通道故障、人工处理完成；显示当前事件及围栏负荷，提供权限受控的人工操作。管理人员可查看日报、未处理事件和维护记录，软件不能把设备故障展示为牛只耳标已损坏。

### 10.13 LIS与农场软件接口

第一版提供本地保存与可审核导出，不宣称已完成LIS直连。取得接口规范及授权后，适配层区分内部通行与法定事件，校验编号与字段、保存提交及回执、防止重复、断网缓存并核对恢复结果。[1], [4], [5]

界面分别显示本地保存、待申报、提交失败及已收到成功回执。改变已有正式身份或上传法定业务前保留审核责任。

### 10.14 定价、吞吐量与验证

规划客户安装价格为18,500英镑，不含增值税和重大土建；年度服务720英镑，能源假设60英镑。详细预算及收益见第12节，均须报价与试验修订。

200头牛90分钟对应约133头／小时。正常工况暂以150头／小时为目标，即平均24秒完成进出、门动作、扫描和处理，而非单纯读取时间。实际任务评价计入重读和正常复核负担；若达不到目标，调整地点、流程或结构，不取消安全确认。

| 阶段 | 验证内容 | 主要判断 |
| --- | --- | --- |
| 台架 | 延迟、重复、通信中断及门位矛盾 | 状态机和事件归属正确 |
| 无动物 | 模拟占用、受阻、急停和失电 | 无未经允许的危险运动 |
| 监督下牛只试验 | 体型、紧跟、停步、倒退 | 分隔和通行可用 |
| 射频与环境 | 邻牛、钢结构、污物及干扰 | 读区和占位有效 |
| 连续农场试点 | 任务、围栏、维护及人工时间 | 效率和净收益可接受 |

分别统计确认正确率、覆盖率、误分流、异常处理率、出口一致性、接管次数和净劳动时间。重复同一牛群不能视为全部独立样本，零观测错误也不代表零风险。先验证分隔、读取归属和安全释放，再验证经济性，最后决定扩大销售或自动化。

## 11. 可持续发展

《乳业路线图：气候雄心》强调以证据支持减排，并考虑资源管理、动物健康和福利；其目标涉及二氧化碳净零及持续降低甲烷、氧化亚氮影响。[23], [24]

ID-Coo优先利用既有通道，采用可更换传感器、控制箱及驱动，避免单个部件失效导致整套报废。钢结构防腐、线缆易检查，减少维修材料浪费。第一版优先评估电动驱动，避免无其他用途时新增持续运行的压缩空气系统。

记录待机、动作和总能耗，并以每千次通行耗电比较。年度能源情景暂按200千瓦时、0.30英镑／千瓦时，合计60英镑，须以实际功率和农场电价替换。

减少再次寻找可能降低重复赶牛，但逐头停留也可能增加等待与应激。试点比较等待、倒退、人工驱赶和拒绝通行。准确记录不能直接证明减少甲烷；生命周期评价须计入制造、电力、维修和报废。若福利或通行负担恶化，须回到第10节修改布局和流程。

## 12. 可负担性

### 12.1 安装与持续费用

以下是概念预算，不是厂商报价。假设已有合适地面、供电、排水及待处理围栏，不含重大土建。

| 项目 | 规划金额／英镑 |
| --- | ---: |
| A、B段结构及通道改造 | 2,600 |
| 五处门控机构及驱动整合 | 3,000 |
| RFID读卡器与天线 | 1,400 |
| 六个超声测点，暂按200英镑／点 | 1,200 |
| 防夹、保护及安全控制 | 1,800 |
| PLC、输入输出及操作界面 | 1,100 |
| 电源、控制箱及后备电源 | 600 |
| 安装、调试与培训 | 1,800 |
| 直接成本小计 | **13,500** |
| 10%预备费 | **1,350** |
| 成本及预备费 | **14,850** |
| 研发、销售、保修及经营费用空间 | **3,650** |
| 客户安装价格，不含增值税 | **18,500** |

3,650英镑不是净利润。预算按至少±30%变化评估并取得实际报价；成本超出时调整价格或非必要功能，不削减安全。年度服务720英镑、能源假设60英镑，合计780英镑，重大损坏及范围外维修另计。

假设五年费用不变，不考虑融资、税务、残值及重大损坏：

```text
五年总拥有成本 TCO5 = 18,500 + 5 × 780 = 22,400英镑
200头牛的平均成本 = 22,400 / (200 × 5) = 22.4英镑／头·年
```

### 12.2 收益与回收期

定义每日净节省劳动h、每小时劳动成本w、有效天数d和其他差错收益L：

```text
年度收益 B = h × w × d + L
年度净收益 S = B − 780
简单回收期 P = 18,500 / S（仅当S > 0）
```

h必须扣除进牛确认、监控、清洁、复核和故障处置。减少记录时间但增加更长值守时，不能把前者全部算作净节省。

基准假设h=1小时／天、w=18英镑／小时、d=365天、L=600英镑／年：B=7,170英镑，S=6,390英镑，回收期约2.90年。L不重复计算人工，也不包括未经证实的产奶增长或依赖避免重大事故的收益。

### 12.3 敏感性与现金承受能力

五年评价、规划折现率8%的净现值为：

```text
NPV = −18,500 + Σ[t=1…5] S / (1.08)^t
```

| 情景 | 每日净节省 | 其他年度收益 | 年度净收益 | 回收期 | 五年净现值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 保守 | 0.4小时 | £0 | £1,848 | 10.01年 | −£11,121 |
| 基准 | 1.0小时 | £600 | £6,390 | 2.90年 | £7,013 |
| 较高收益 | 1.5小时 | £1,200 | £10,275 | 1.80年 | £22,525 |

其余基准假设不变，实现三年简单回收需每日净节省约0.97小时。因此，安装前应观察代表性劳动时间；低于门槛时考虑手持读取或人工流程改进。

Defra的2024／25年度英格兰奶业农场平均Farm Business Income为153,800英镑。[22] 18,500英镑约占其12%，只表明规模，不证明现金可用或每家都可负担。农场差异、债务及其他支出须逐户核对。分期改变付款节奏，不提高项目本身收益。
