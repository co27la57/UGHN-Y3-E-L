# 牛只分流方案

更新日期：2026-10-12  
阶段：机械分流布局暂定采用；超声波与 RFID 集成方案处于概念设计，尚未完成样机验证。

## 1. 当前目标与范围

为目标荷斯坦—弗里斯兰牛设计逐头通行和异常分流装置：牛只进入单列通道，在最末端的独立段完成检测；正常牛返回正常通道，需要复核的牛进入旁侧独立围栏。

机械分隔、通行控制和出口分流布局暂定采用。新增初步技术分工：**空气耦合超声测距用于通道占位、进出过程及疑似跟入监测；RFID 用于读取电子耳标和记录编号；分隔门与分流门执行通行控制。**具体传感器型号、安装位置、判定阈值和扫描时间仍需验证。

目标是分离正常通过的牛与耳标损坏或缺失、需要复核的牛。但目前“超声测距＋RFID”能直接筛出的主要是电子耳标读取异常，不能完整判定耳标外观损坏或非电子耳标缺失。详细改进及能力边界见第 10 节。

本文记录对话中提出的当前建议，不代表全部结构、尺寸和控制细节已经定型。

## 2. 可行性判断

“逐头控制通行 → 末段检测 → 按结果选择出口”的结构在概念上可行。Arrowquip 官网已有可调单列通道、滑动分隔门及末端分流模块，可作为机械结构参考。

仍需解决的关键问题是：

- 两头牛紧跟时，能否安全隔出一头；
- 检测结果能否始终对应当前末段内的牛；
- 分流门能否在放行前可靠到位；
- 当前牛离开后，能否确认检测段及分流区已经清空；
- 异常围栏中的牛能否被留在围栏内，避免返回主通道。

官网资料支持机械结构的参考价值，但不证明本方案已实现自动逐头进牛或自动异常分流。

## 4. 当前建议布局

用户最初构想是多个段，每段容纳一头牛，最后一段检测。当前建议先以一个单头缓冲段和一个末端检测段验证核心流程，再根据现场排队需求增加前部通道段。

```text
牛群等待区
    │
入口分隔门 G0
    │
单头缓冲段 A
    │
检测段后门 G1
    │
末端检测段 B
    │
检测段前门 G2
    │
分流区及分流门 D ──→ 异常支路 → 围栏入口门 H → 异常待复核围栏
    │
    └────────────→ 正常返回通道
```

该图表达功能连接关系，不表示实际比例、门的转轴位置或运动范围。

正常牛和异常牛均向前离开检测段。异常牛通过支路进入围栏，避免要求其倒退或由人员在通道内横向驱赶。

分流门应封住不应进入的路径，并形成连续的导向边界。**不能把分流门用作推动或挤压牛身的装置。**

## 5. 单头容纳与进牛控制

“每段一头牛”必须由分隔结构与占位确认共同实现，不能仅靠固定段长保证。

第一头牛进入时，第二头可能紧贴跟入或探入头颈；此时直接关门可能夹到前牛后肢或后牛头颈。因此，入口分隔方式、防夹和占位确认仍是重点待验证内容。

控制要求：

1. 向下一段转移前，确认下一段为空，并确认本次放行对象已与后方牛群隔开。
2. 检测段前门 G2 关闭、缓冲段 A 中已确认隔出一头牛时，才允许打开 G1。
3. 牛完整进入 B、关门区域没有身体占用后，才允许关闭 G1。
4. 确认 B 中只有一头牛，且 G1、G2 均已关闭，才开始检测。
5. 分流放行期间保持 G1 关闭，阻止下一头牛跟入。
6. 无法确认单头占位时，暂停本轮检测与继续进牛，等待处理。

占位确认初步采用多测点超声监测辅助实现。门位反馈和防夹功能仍需独立设计，不能把普通超声测距传感器作为唯一防夹保障。超声占位结果本身不能证明段内只有一头牛，须结合机械分隔和经验证的进牛流程。

## 6. 末端检测与分流动作顺序

| 步骤        | 动作                        | 前提或完成条件               |
| --------- | ------------------------- | --------------------- |
| 1. 准备接牛   | G2 保持关闭，打开 G1             | B 为空；A 内已安全隔出一头牛      |
| 2. 建立单头空间 | 牛完整进入 B 后关闭 G1            | 关门区域无身体占用，B 内确认只有一头牛  |
| 3. 检测     | G1、G2 均关闭，接收当前检测结果        | 当前牛仍留在 B 内            |
| 4. 设置出口   | 正常选择主路；需要复核或结果不确定选择异常支路   | 分流区无占用，目标通道畅通；异常围栏可接收 |
| 5. 放行     | D 到位并确认后，打开 G2            | G1 保持关闭，禁止后牛跟入        |
| 6. 确认离开   | 确认牛完整通过分流区；异常牛完整进入围栏后关闭 H | 关门区域无身体占用，当前牛去向已确认    |
| 7. 恢复接牛   | 安全关闭 G2，完成必要复位，结束本轮       | B 与分流区清空后，才能进入下一轮     |

核心顺序为：**先判断 → 先设置分流方向 → 确认到位 → 再放牛。**

当前牛占用分流门的运动区域时，不得切换方向。不能只按固定时间推定牛已经离开。

若 RFID 没有读到编号，分流控制仍可以把“当前 B 内的牛”作为本轮对象送入复核围栏，不必先知道其身份编号。控制过程须保持本轮对象与检测结果的对应关系，避免结果延迟后作用于下一头牛。

## 7. 异常待复核围栏

围栏用于暂存需要人工复核的牛。RFID 未读到或身份不确定，不等同于牛患病，因此当前将其定义为“异常待复核围栏”，不赋予疾病隔离功能。

设计要求：

- 设置独立入口及防返回控制，防止牛退回分流区；
- 入口门 H 只能在牛完整通过且门口无身体占用后关闭；
- 设置独立的人工处理或释放出口，避免经主检测通道倒退返回；
- 围栏满员或支路堵塞时，禁止继续送入，并暂停上游接牛；
- 人员能够在围栏外操作门，并保留安全处置空间。

围栏容量、支路长度、入口结构和现场布置尚未确定。

## 8. 在官方机械结构上需要补充的设计

| 项目    | 需要补充的内容                         |
| ----- | ------------------------------- |
| 逐头进牛  | 入口分隔方式、单头占位确认，以及相邻门的联锁          |
| 自动门动作 | 分隔门与分流门的驱动、锁定和到位反馈              |
| 防夹    | 门运动区域占用确认，以及受阻时的安全停止或退让策略       |
| 检测接口  | 当前牛对应的正常、需要复核或结果不确定信息           |
| 离开确认  | 检测段、分流区及围栏入口的通过与清空确认            |
| 异常处理  | 门未到位、牛拒绝移动、支路堵塞、围栏满员等情况的暂停与人工处置 |
| 人工接管  | 从设备外操作、解除故障和安全释放牛只的方式           |

检测结果不确定且异常支路可用时，可送入待复核围栏。机械状态不确定或出口不可用时，应暂停接牛并处理，不能强行关门或放行。

失电、驱动故障和紧急停机时的门状态及释放方式，仍需专门设计；不能简单规定所有门立即关闭。

## 9. 第一版验证与后续扩展

建议第一版先验证“一个单头缓冲段＋一个末端检测段＋一个双出口分流区”。

增加前部单头段可以增加缓冲容量，但不一定提高末端检测与分流的处理速度，同时会增加门、驱动机构、停走次数和故障点。

优先验证以下场景：

1. 两头牛紧跟时能否安全隔开，无夹伤风险。
2. 不同体型牛能否完整进入末段、停留并顺利离开。
3. 两条出口能否形成清晰、顺畅的通行路径。
4. 连续异常牛能否依次进入已有牛的待复核围栏。
5. 牛停步、倒退或未完全离开时，系统能否避免提前切门。
6. 检测结果延迟时，能否保持结果与当前牛的对应关系。
7. 围栏满员、支路堵塞或门未到位时，能否停止继续进牛并人工接管。

段长、有效净宽、门运动空间、支路角度和围栏容量，应结合目标牛群测量与现场试验确定。当前不锁定施工尺寸、处理速度、成本或采购型号。

## 10. 超声波与 RFID 集成改进

### 10.1 技术分工及能力边界

| 子系统      | 用途                               | 不能据此直接下结论的情况                                    |
| -------- | -------------------------------- | ----------------------------------------------- |
| 空气耦合超声测距 | 辅助检测占位、进入、离开和疑似跟入，作为是否允许扫描或放行的条件 | 普通测距不能识别牛的身份，不能可靠判定耳标损坏或缺失，也不能独立准确区分紧贴的两头牛      |
| RFID     | 读取兼容电子耳标中的编号，提供本轮标签读取结果          | 一个编号不等于只有一头牛；无编号不等于已证实耳标缺失或损坏；普通印刷耳标不能用 RFID 读取 |
| 分隔门和分流门  | 阻断跟入，保持检测对象隔离，选择出口               | 超声发现异常不能代替机械阻断；门动作还须满足到位反馈和防夹条件                 |

若耳标外壳损坏但芯片仍可读，或缺失的是非电子耳标，本组合可能无法发现。如果最终要求覆盖全部物理损坏或缺失，须补充人工目检或专门外观检查；该功能尚未选定。

### 10.2 初步测点布置

下表为功能测点建议，不表示已确定传感器数量或安装高度。

| 测点        | 建议位置                   | 作用                            |
| --------- | ---------------------- | ----------------------------- |
| U-A       | 单头缓冲段 A                | 辅助确认空段／占用，与入口门 G0 配合建立单头缓冲状态  |
| U-IN      | G1 附近                  | 监测进牛过程及疑似后牛探入；门口完整覆盖另需防夹设计    |
| U-B1、U-B2 | 检测段 B 的前后位置，优先评估顶部向下安装 | 判断段内占用变化及牛是否进入预定读区，辅助发现异常通行过程 |
| U-N       | 正常出口                   | 确认正常路径实际通过与清空                 |
| U-Q       | 异常支路／围栏入口              | 确认异常路径实际通过及入口清空               |

RFID 天线布置在 B 内预定的头耳通过区域，按耳标类型、实际头位变化及厂家要求确定布置。需测试两耳不同位置、邻段牛以及钢制通道对读取的影响，避免误把邻牛编号绑定到当前牛。机械隔开牛只并不等于隔开射频读区。

超声背景基准应在空通道时采集，区分“空／占用／不确定”。不得把没有回波直接认定为空，也不得把一个回波峰解释为一头牛。两头牛紧贴时可能形成连续占用，与一头较长的牛难以区分。

### 10.3 联锁和扫描流程

1. B 及分流区清空、G2 关闭；A 经机械进牛流程建立单头状态，G0 已关闭并确认后，才允许打开 G1。
2. 监测当前牛进入 B；确认关门区域安全后关闭 G1。G1 和 G2 均关闭，当前牛处于可读区域且无疑似跟入异常，才启动本轮有效 RFID 扫描。
3. 每次进牛建立独立的通行事件编号，记录扫描窗口内的原始读数；同一编号的重复读取在本轮判定时去重。
4. 无读数或读数存在歧义时，执行有限时间、有限次数的重读。窗口与重试参数通过现场试验确定，不能无限等待牛只停留。
5. 根据下表形成分流决定；先确认目标出口畅通、D 到位，再打开 G2，放行期间 G1 保持关闭。
6. 用对应出口的通过记录确认实际去向。当前牛完全离开、门运动区域安全后完成关门复位，再接下一头。

G0 与 G1 不同时开放以保持缓冲隔离；G1 与 G2 不同时开放以保持检测隔离。这些联锁仍不能独立保证入口首次只进一头，首次进牛与紧跟分隔必须单独验证。

### 10.4 分流判定

| 状态                                         | 处理                         | 记录原因                       |
| ------------------------------------------ | -------------------------- | -------------------------- |
| 通行状态有效、RFID 设备状态正常，本轮获得一个可归属当前牛的有效编号，无其他异常 | 正常通道                       | 电子耳标读取通过；不代表耳标外观已检查        |
| 确认有牛，设备诊断未见故障，完成有限重读后仍无有效编号                | 异常待复核围栏，前提是支路可用            | 电子耳标未读到；缺失、损坏、姿态或读区问题待人工确认 |
| 同一轮读到不同编号，或编号归属不清                          | 暂停判定并重读；单头状态确认后仍有歧义，可送复核围栏 | 身份读取歧义，不能直接等同于多牛           |
| 疑似多牛、占位不确定或门口被占用                           | 暂停进牛与自动放行，安全重新分隔或人工接管      | 通行状态异常；不得把同一批多个牛当作单牛继续分流   |
| 超声失效、RFID 离线／天线异常、门未到位、出口堵塞或围栏满员           | 暂停接牛并处理                    | 设备或路径故障，不能批量判为耳标损坏         |

读卡器的诊断正常不保证每次射频读取一定成功；“未读到”仍是复核原因，不能自动写成已确认损坏。

### 10.5 数据记录

以一次通行事件为单位记录：事件编号、开始与结束时间、超声状态摘要、门位状态、RFID 原始读数与去重结果、设备诊断、分流原因、计划出口、实际出口确认及人工复核结果。

无耳标读数时，正式牛只身份字段保持为空，使用临时通行事件编号管理复核。不能凭牛群排列顺序推测其正式身份。后续人工确认身份后补充关联，并保留修改记录。

### 10.6 新增验证项目

- 用不同体型、姿态和毛况的牛测试超声回波及占位判定，验证金属栏杆、门、污物和气流的影响。
- 多个超声传感器须按厂家要求避免串扰，可评估支持同步或错时发射的型号；同时验证错时测量增加的响应延迟。
- 对超声盲区、无回波、数据过期等状态设置“不确定”，不得按空通道处理。
- 门边防夹采用经验证的覆盖与受阻保护方案，普通超声测点不能成为唯一保护。
- 测试完好可读耳标、电子失效耳标、缺失电子耳标、邻牛串读、外壳损坏但仍可读等情况，分别记录误分流和漏检。
- 连续多次无读数时提示设备诊断检查，避免读卡器故障导致整批牛被分流。
