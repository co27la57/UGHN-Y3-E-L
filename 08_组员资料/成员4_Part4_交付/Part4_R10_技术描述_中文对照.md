## 10. 解决方案技术描述

*本节提交给直属主管。第一版为概念设计：人员从通道外确认单头进牛；系统随后自动完成读取、判定与分流。以下内容均未在农场验证——10.7 节定义了销售前必须证明的事项。两张图均非施工图。*

### 10.1 物理结构

牛只沿单列通道行进：等待区 → 门 G0 → 缓冲段 A → 门 G1 → 检测段 B → 门 G2 → 带分流门 D 的分流区（图 1）。读取完成后，分流门 D 在两个出口中选择其一：正常返回通道，或经围栏入口门 H 通往待复核围栏的异常支路。所有牛都向前离开 B 段；D 只构成导向边界，绝不推挤牛身。第一版只用一个缓冲段和一个检测段；增加前部段只增加等待容量、不提高末端处理速度，反而增加门与故障点。可调式商用通道（宽约 526–800 毫米，8 英尺与 10 英尺模块）仅指示结构包络 \[13\]\[14\]；防倒退挡杆可辅助控制倒退，但绝不能代替分隔门。段长、净宽与天线安装高度按目标品种采用 CIGR 标准体尺——成年荷斯坦—弗里斯兰泌乳牛薯甲高约 1.4 米（CIGR 标准 650–749 kg 档为 1.44 米 \[26\]；1,054 头 HF 实测均值 1.41 米 \[27\]），体长约 1.71–1.75 米、胸宽约 0.60 米 \[26\]\[27\]；日后换其他品种只需在同一张表重新取参，无需重新设计。最终尺寸与门的活动范围以现场勘测为准，且模块长度绝不默认等于单头牛的容纳长度。结构按处理福利设计——防滑排水、无尖锐突出物、门轨与铰链防护、头颈与腿部间隙、连续出口边界及围栏外操作位置 \[9\]；保定（夹持）设备仅作参考选项，本设计不默认需要固定牛头。（UR8、UR9）

待复核围栏是暂存待人工复核牛的设施，不承担疾病隔离功能。它设独立防返回入口与独立的人工处理出口；H 门只能在牛完整通过后关闭；围栏满员或支路堵塞时停止送牛并暂停上游接牛。人员可在围栏外操作门，并保留安全处置空间。容量按 C ≥ λq × th + Cm（异常进入速率 × 处理间隔 + 容量余量）规划——该平均负荷关系不覆盖连续异常情形，因此满员监测必须保留。预算情景复用约 6 头容量的既有待处理围栏；作为设计底线，分流围栏至少应能容纳挤奶厅一侧的牛，并保障饮水、饲料与躺卧空间 \[26\]。

### 10.2 感知设备与能力边界

系统采用两种感知模态，各自有明确的能力边界（见下表）。低频 RFID 读卡器（ISO 11784/11785，支持 HDX 与 FDX-B；以 Tru-Test XRP2/XRP2i 作功能参考，最终型号经现场选型）通过安装在 B 段头耳通过区外侧的天线，读取已佩戴的低频电子耳标 \[11\]\[12]。未佩戴此类电子耳标的牛须转人工核对身份或采用替代流程；未读到编号本身不证明耳标损坏。六个超声测点（U-A、U-IN、U-B1、U-B2、U-N、U-Q；U-B1/U-B2 优先评估顶部向下安装）监测占位与通行：距离 d = c·Δt/2 与空通道时采集的背景基准比较，每个测点输出**空 / 占用 / 不确定**三态——无回波、数据过期或设备故障一律归为"不确定"而非"空"，且单一回波峰绝不计为一头牛 [15]。评估多传感器采用厂家支持的错时发射以抑制串扰 [16]。六个测点为规划配置：分流区或入口覆盖不足时须增设测点——绝不因预算留下盲区。

| 子系统   | 功能            | 能力边界                    |
| ----- | ------------- | ----------------------- |
| 机械分隔  | 建立单头空间；阻断跟入   | 不能证明射频读区内没有邻牛           |
| 超声测距  | 占位、进出过程、疑似跟入  | 不能识别牛只身份，也不能证明牛的数量      |
| RFID  | 读取电子耳标编号      | 不能证明标签外观完好、读取失败的原因，也不能证明一个编号就等于一头牛 |
| 门控与分流 | 执行已确认的通行与出口选择 | 不做诊断，不做官方身份认定           |
| 人工复核  | 检查耳标、核对记录     | 绝不按排队顺序猜测身份 [3]         |

机械分隔不能分隔射频读区——即使 B 段内只有一头牛，天线也可能读到邻牛编号，因此读数归属须经专门测试（见 10.7）；耳标外壳破裂但芯片仍可读、或缺失的是非电子耳标，均在自动检测能力之外，需要人工目检。（UR1–UR3、UR9）

### 10.3 控制硬件、电气与安全

概念接口见下表（图 2）；具体电压、驱动功率、线缆保护及接地方案按所选设备与现场设计确定——本节内容不构成施工电路图。PLC 向门驱动直接发出动作请求；另一路安全相关控制监测经现场风险评估确定的保护装置，并能独立停止或禁止门驱动，软件与数据接口均不能绕过。安全功能及所需性能按 ISO 13849-1 经现场风险评估确定——引用该标准不声称达到任何性能等级 [25]。防夹保护由经验证的覆盖检测、受阻响应与机械防护共同构成；超声测点绝不是唯一的防夹手段。失电时系统停止危险运动并保持确定、受控的门状态（并非所有门简单地关闭或打开）；短时后备电源维持控制器存活，以保存状态并发出提示。人员可在设备外解除驱动并释放牛只；复电后系统先核实实际门位与占位状态再恢复运行，绝不接续被打断的危险动作。使用、培训与检查遵循 HSE 牲畜作业指导 [8]。（UR4、UR5）

| 接口 | 信号或数据 |
| --- | --- |
| 超声传感器 → PLC | 距离、占位状态、更新时间及诊断 |
| RFID 读卡器 → PLC | 耳标编号、接收时间及设备状态 |
| 门位反馈 → PLC | 开位、关位和故障状态；设有门锁时报告锁定状态 |
| 安全装置 → 安全相关控制 | 由风险评估确定的急停、防护和其他保护输入 |
| PLC → 门驱动 | 开、关或停止动作请求 |
| 安全相关控制 → 门驱动 | 独立停止或禁止驱动 |
| PLC ↔ 本地事件日志与农场主界面 | 事件及设备状态；授权人工操作作为过程请求返回 PLC |
| 本地事件日志与界面 → 农场软件 | 第一版可审计导出 |

### 10.4 控制算法与分流逻辑

采用规则状态机，每次通行作为**独立事件**运行；第一版不需要机器学习。

| 状态      | 动作             | 进入下一状态的条件           |
| ------- | -------------- | ------------------- |
| S0 自检   | 检查设备、保护装置与门位   | 满足启动条件              |
| S1 单头缓冲 | 人员确认 A 段内只有一头牛 | G0 已关闭，分隔有效         |
| S2 进入   | G2 保持关闭，打开 G1  | 牛完整进入 B 段，关门区域无身体占用 |
| S3 隔离扫描 | 关闭 G1，开启扫描窗口   | G1 与 G2 均确认关闭       |
| S4 判定   | 读数去重、核对归属、有限重读 | 得到有效身份或复核结论         |
| S5 设置出口 | 检查路径，设置分流门 D   | 目标出口可用，D 已到位        |
| S6 放行   | 打开 G2；G1 保持关闭  | 当前牛已离开 B 段          |
| S7 复位   | 核实实际出口，安全关门    | B 段与分流区已清空          |
| SF 故障   | 停止接牛，提示处理      | 故障排除，人员确认恢复         |

过程联锁规则：G0 与 G1 绝不同时打开，G1 与 G2 也绝不同时打开；只有两者均确认关闭、牛处于读区且无疑似跟入时才开始扫描；D 必须在 G2 打开前到位；牛占用 D 的运动范围时绝不切换出口；绝不按定时假定牛已离开。已结束事件的延迟结果仅保留在日志中，**绝不作用于下一头牛**。这些过程联锁本身不能独立保证入口首次只进一头——首次进牛与紧跟分隔必须单独验证。只有在自动分隔、防夹与异常处理均通过验证后，才取消人工确认单头进牛；第一版的经济测算须计入人员时间。

| 情况                       | 处理                     |
| ------------------------ | ---------------------- |
| 有效单头通行、获得一个可归属的编号、无其他异常  | 正常返回（不代表耳标外观已检查）         |
| 有牛在场、有限重读已用尽、未检测到读卡器故障   | 支路可用时送异常支路——原因记为"未读到"  |
| 读到多个编号或归属不清              | 牛留在 B 段有限重读；仍不明确则送复核围栏 |
| 疑似多头、占位不确定、门口被占用         | 暂停；安全重新分隔或人工接管         |
| 读卡器离线、超声故障、门故障、支路堵塞、围栏满员 | 暂停接牛——绝不批量标记为耳标损坏      |

无读数的牛在 B 段内仍由其事件编号管理；但当机械状态未知时，自动分流停止；连续无读数触发读卡器诊断，避免故障读卡器把整群牛错误分流。（UR1–UR5）

### 10.5 数据、软件与农场主界面

每次事件记录：事件编号、开始与结束、扫描与放行时间、占位与门位摘要、原始与去重读数、设备诊断、判定原因、计划与实际出口、处理人员及修改历史。事件编号与官方身份分开：无编号时身份字段保持为空，人工核实后建立关联，并保留原始异常与更改记录 [3]；两侧官方可视标识均不足时，按官方程序核查，**绝不创建替代正式编号**。界面显示四种状态——电子核验通过、身份待复核、设备/通道故障、人工处理完成——以及当前事件与围栏负荷，提供权限受控的人工操作，以及包含未处理事件和维护记录的日报。读卡器故障绝不能显示为"耳标损坏"。（UR5–UR7）

### 10.6 LIS 与农场软件接口

第一版本地保存并生成可审计导出；**不声称已直连 LIS**。取得接口规范与授权后，适配层将区分内部通行与须申报的法定移动，校验编号与字段，保存提交与回执，防止重复，并在断网时缓存提交 \[1\]\[4\]\[5]。界面区分本地已保存、待申报、提交失败与已收到回执四种状态；更改既有官方身份或提交法定申报时保留人工审核环节。（UR6、UR7）

### 10.7 定价、吞吐与验证

规划定价为**安装费 18,500 英镑**（不含增值税与重大土建），**年度服务 720 英镑**，能源按 **60 英镑/年**假设——这是第 12 节可负担性论证的基础；设计通过复用既有通道与围栏，把感知、门控与安全控制在这一价格包络内实现。吞吐目标为 **150 头/小时**（每头约 24 秒完成进出、门动作、扫描与处理），对照试验要求 200 头 90 分钟（约 133 头/小时），其中计入重读与复核；若达不到目标，调整地点、流程或结构——**安全确认环节绝不削减**。（UR8、UR10）

| 验证阶段    | 验证内容              | 通过标准       |
| ------- | ----------------- | ---------- |
| 台架      | 延迟、重复读数、通信中断、门位矛盾 | 状态机与事件归属正确 |
| 无动物     | 模拟占位、受阻、急停、失电     | 无未经允许的危险运动 |
| 监督下牛只试验 | 体型差异、紧跟、停步、倒退     | 分隔与通行可用    |
| 射频与环境   | 邻牛读取、钢结构、污物、干扰    | 读区与占位判定有效  |
| 耳标状态     | 完好可读、电子失效、缺失、外壳损坏可读、邻牛串读 | 分别记录误分流与漏检 |
| 农场连续试点  | 任务、围栏、维护、人员时间     | 效率与净收益可接受  |

各阶段分别统计：已确认读数的正确率与覆盖率、误分流率、异常处理率、出口一致性、人工接管次数与净劳动时间。重复使用同一牛群不构成独立样本，零观测错误不等于零风险。先证明分隔、读数归属与安全释放，再验证经济性。（UR1–UR10）
